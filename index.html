Sistema de Cadastro de Motores em Python

Documentação técnica do algoritmo monolítico desenvolvido para gerenciamento de motores elétricos em memória.

Sobre o Projeto e Local de Desenvolvimento

Este software foi desenvolvido durante as atividades práticas de programação realizadas no SENAI, dentro da unidade de ensino técnico localizada nas dependências da WEG (CentroWEG), em Jaraguá do Sul, Santa Catarina.

Inspirado no portfólio industrial de motores elétricos da própria WEG, o sistema simula um cadastro rápido de especificações técnicas (código, modelo, potência, rotação em RPM e tensão) utilizando apenas estruturas nativas da linguagem Python, sem dependência de banco de dados externo.

Arquitetura e Funcionamento do Código

O programa foi estruturado de forma monolítica (todo contido em um único arquivo .py) para facilitar testes locais e compreensão da lógica procedural.

1. Armazenamento em Array (Lista)

A variável global motores = [] atua como um vetor dinâmico em memória RAM. Cada motor cadastrado é armazenado como um dicionário contendo suas chaves e valores técnicos.

2. Modularização por Funções

Cada operação do sistema foi isolada em uma função específica, aplicando o padrão CRUD (Create, Read, Update, Delete) e facilitando a leitura do código.

3. Validação e Integridade

Antes de inserir um novo item, o algoritmo percorre o array para impedir códigos duplicados. Na edição, o usuário pode pressionar ENTER para preservar dados existentes.

4. Loop de Execução

A função menu() utiliza um laço while True que mantém o terminal interativo ativo até que a opção de saída seja acionada.

Mapeamento das Funções do Sistema

Função Operação CRUD Descrição Técnica
cadastrar_motor() Create (Criar) Coleta os dados do motor, valida se o código já existe e adiciona o dicionário à lista.
listar_motores() Read (Ler) Percorre o array com enumerate() e exibe todos os motores formatados no console.
buscar_motor() Read (Filtrar) Realiza busca parcial (case-insensitive) por código ou modelo utilizando List Comprehension.
editar_motor() Update (Atualizar) Localiza o motor pelo código e atualiza apenas os campos preenchidos pelo usuário.
remover_motor() Delete (Excluir) Encontra o índice do registro no array e remove o item através do método .pop().
menu() Controle Gerencia a interface de linha de comando (CLI) e direciona o fluxo para cada função.

Trecho Principal da Estrutura de Dados

Abaixo está a representação de como cada motor é estruturado dentro do array em Python:

motores = []

motor = {
    "codigo": "W22-001",
    "modelo": "WEG W22 IR3 Premium",
    "potencia": "10 CV",
    "rotacao": "1750",
    "tensao": "220V/380V"
}

motores.append(motor)
